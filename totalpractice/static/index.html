24시간 정상 운영일의 총 수요를 예측합니다. 날씨는 직접 입력해 주세요.

02 / PREDICTION

예상 자전거 대여량

—대 / 일

조건을 입력하면 예측 결과가 여기에 표시됩니다.

검증 데이터 R²—

모델이 검증 데이터의 대여량 변동을 설명하는 정도입니다. 이번 예측의 확률이나 정확도를 뜻하지 않습니다.

평균 절대 오차 (MAE)—

일별 총 대여량의 평균 절대 오차입니다. 개별 예측의 오차 범위를 보장하지 않습니다.

모델의 원본 예측이 음수여서 화면에는 0대로 표시했습니다.

HOW IT WORKS

입력부터 예측까지

  1. 날짜와 날씨 조건 입력
  2. 저장된 전처리 · Ridge 모델로 예측
  3. 예상 대여량과 검증 성능 확인

과거 서울 자전거 데이터를 학습한 결과로, 실제 대여량과 차이가 있을 수 있습니다.
